# ADR-0022 画像の保存の名前を日付と乱数で作り、上書きしない

> 状態: 推定 | 確認日: 2026-10-24 | 対象: `src/app/api/admin/news/route.ts`、`src/app/api/admin/news/[id]/route.ts` | 基準コミット: `a03beaff`

## 概要

書き込む画像は `news/<YYYY-MM-DD>/<uuid>.<拡張子>` の名前で置き場に入れ、同じ名前があっても上書きしない。

## 判断

### ADR-0022 画像の保存の名前を日付と乱数で作り、上書きしない

| 属性 | 値 |
| --- | --- |
| 上位 | DRV-NEWS-010 |
| 根拠 | 送られたファイルの名前を使わず日付と uuid で名前を作れば、同じ名前の上書きが起きず、道から中身やほかの記事の画像を推し量られにくいため（推定。記録は無い）。拡張子を確かめた MIME から決めれば、`.html` などの名前で置き場に入らない（作る時だけ。直す時はファイル名から取る） |
| 状態 | 推定 |
| 出どころ | 実装から推定 |

#### 背景

画像は service role で非公開の置き場に書き込む（ADR-0001・0005）。保存の名前を誰が決めるかを決める必要があった。

#### 決定

- 作る時は `news/<YYYY-MM-DD>/<uuid>.<MIME から決めた拡張子>`、`upsert: false`、`cacheControl: '3600'`（`route.ts`）

#### 退けた案

記録なし

#### 結果

- 良くなること: 名前のぶつかりと上書きが起きない
- 食い違い: 直す時（PUT）は拡張子を、送ったファイルの名前の最後の `.` の後ろから取る（`[id]/route.ts`）。作る時の決まりと合わない（SEC-NEWS-017-AC-02）

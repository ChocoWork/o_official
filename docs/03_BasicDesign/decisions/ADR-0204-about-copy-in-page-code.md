# ADR-0204 ABOUT の文はページのコードに直に書き、DB や管理画面から読まない

> 状態: 推定 | 確認日: 2026-10-24 | 対象: `src/app/about/page.tsx` | 基準コミット: `a03beaff`

## 概要

ABOUT の見出し・本文・3つの原則・締めの文・ページの題と説明は、どれもページのコードに直に書く。NEWS や LOOK と違い、DB・外のサービス・管理画面の文を読まない。

## 範囲と根拠

| 項目 | 内容 |
| --- | --- |
| 範囲 | `scripts/trace/scope.json` の ABOUT |
| 対応する ID | SEC-ABOUT-006 |
| 対象のコード | `src/app/about/page.tsx`（読み込むのは Next の型と共有のボタンの部品だけ。題・説明・OG を返す関数、3つの原則の配列、本文と CTA の文） |
| 比べた相手 | NEWS は `src/features/news/services/public.ts`、LOOK は `src/lib/look/server.ts` で公開の記事を DB から読む |
| 要件の文書 | `docs/02_Requirements/areas/about.md` |
| 調べた時点 | 2026-10-24 の作業ツリー（コードは読んだだけで、動かしての確かめはしていない） |

## 判断

### ADR-0204 ABOUT の文はページのコードに直に書き、DB や管理画面から読まない

| 属性 | 値 |
| --- | --- |
| 上位 | SEC-ABOUT-006 |
| 根拠 | ブランドの思想の文は滅多に変わらず、運営が日々書き足す NEWS・LOOK と違って管理画面で直す仕組みが要らないため（推定）。DB を読まないので、1回の要求の重さが描画だけで済み、DB や外のサービスが止まっても ABOUT を出せる（SEC-ABOUT-006） |
| 状態 | 推定 |
| 出どころ | 実装から推定（決めた記録は見つからない） |

#### 背景

- ABOUT はブランドの思想・ものづくりの理由・取り組み・商品設計の考え方を紹介するページで、中身は `docs/01_Planning/brand.md` の思想から書いた文
- 同じ公開のページでも、NEWS・LOOK・STOCKIST は管理画面で書いた記事を DB から読む

#### 決定

- 文はすべてページのコードの中に字で書く。3つの原則は固定の3件の配列にする
- ページの題・説明・OG の画像も、ページのコードの中の metadata の関数が固定の値で返す
- データの取得・入力・API・Server Action を持たない

#### 退けた案

| 案 | 退けた理由 |
| --- | --- |
| 文を DB に置き、管理画面で直せるようにする | 記録は無い。変える頻度が低く、DB に頼ると DB の停止で ABOUT も出なくなる（推定） |

#### 結果

- 良くなること: DB・外のサービスの状態に関わらず ABOUT を出せる。読み取りの権限や入力の守りを考える所が無い
- 悪くなること: 文を直すにはコードを変えてデプロイし直す。`brand.md` との言い回しのずれ（例: 説明の「天然繊維100%」と本文の「天然繊維を中心に」）がコードの中で起き、管理画面からは直せない
- 範囲外の前提: 描画は共有の `src/app/layout.tsx` の設定で毎回サーバーで行う（静的な生成ではない）。ABOUT の側では変えられない
- 試験: SEC-ABOUT-006-AC-01（DB に届かない状態でも表示される）を試す E2E はまだ無い

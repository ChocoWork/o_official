# ADR-0101 ホームのヒーローはブランド名だけにし、コンセプトの文や CTA を置かない

> 状態: 推定 | 確認日: 2026-10-24 | 対象: `src/app/page.tsx` | 基準コミット: `a03beaff`

## 概要

ホームの最初の画面（ヒーロー）には写真とブランド名の h1 だけを置き、コンセプトの文・価値の訴求・商品一覧へのボタンは置かない。UI/UX レビューの案に対し、ユーザーが「名前のみ」を選んだ。

| 対応する ID | FR-HOME-001、DRV-HOME-001 |

| 要件の文書 | `docs/02_Requirements/areas/home.md` |

## 判断

### ADR-0101 ホームのヒーローはブランド名だけにし、コンセプトの文や CTA を置かない

| 属性 | 値 |
| --- | --- |
| 上位 | FR-HOME-001、DRV-HOME-001 |
| 根拠 | ブランドの世界観は「静かで強い」で、最初の画面に言葉やボタンを足すと崩れる。UI/UX レビュー H-1 は、考えに共感して買う中心の利用者に第一画面で価値が伝わらないとして、コンセプトの文と CTA を足す案を出した。ユーザーはこれに対し、ヒーローは名前のみを残し、考えは下の節で伝える方を選んだ |
| 状態 | 推定 |
| 出どころ | `docs/05_Quality/reviews/uiux/uiux_review_home.md`（2026-06-20、AskUserQuestion で「名前のみ＋直下に新節」を選択） |

#### 背景

- H-1: ヒーローがブランド名の h1 だけで、コンセプトの文・差別化・次の行動（CTA）が第一画面に無い、という指摘（`uiux_review_home.md`）
- 同じレビューは、ブランドに合わせて「CTA を色と大きさで突出させない」「動きは最小限」と、汎用の UI の指針に意図して従わない判断も書いている（`uiux_review_home.md`）
- 付録 D のワイヤーは、ヒーローにフル幅のスライダーと CTA を置き（WF-HOME-003）、ファーストビューに CTA を求める（AC-WF-HOME-001）

#### 決定

- ヒーローに置くのは、写真・字を読みやすくする暗い重ね・ブランド名の h1・SCROLL の印（`src/app/page.tsx` の `Home` の最初の `section` の中身）だけ
- ブランドの考えと `/about` への導線は、下の ABOUT の区画に置く（ADR-0102）

#### 退けた案

| 案 | 退けた理由 |
| --- | --- |
| h1 の下にコンセプトの一文と価値の訴求、VIEW COLLECTION（`/item`）の CTA を1つ置く（H-1 の修正案） | ユーザーが「名前のみ」を選んだ（`uiux_review_home.md`） |
| フル幅のスライダーと CTA（付録 D の WF-HOME-003・AC-WF-HOME-001） | 上と同じく第一画面に CTA を置く形で、ユーザーの選択と逆。付録 D は今の作りより古い版と推定 |

#### 結果

- 良くなること: 最初の画面が写真と名前だけになり、ブランドの静けさが保たれる
- 悪くなること: 第一画面で価値の言葉と次の行動が示されない。考えに共感して買う人は、下まで読まないと違いを知れない（H-1・H-8 の懸念が残る）
- 付録 D の WF-HOME-003・AC-WF-HOME-001 とは食い違ったまま。ID の形が検査の種類に無いので、要件の文書には写していない
- 静かなヒーローに控えめな動きを足す要求は FREQ-278・282 に続いた（ADR-0103）

# ADR-0023 記事の削除は確かめた後に行を消し、戻す手段を持たない

> 状態: 推定 | 確認日: 2026-10-24 | 対象: `src/app/api/admin/news/[id]/route.ts`、`src/components/NewsSection.tsx` | 基準コミット: `a03beaff`

## 概要

管理の画面で削除を確かめた後、`news_articles` の行を消す。消した記事を戻す手段は持たない。

## 判断

### ADR-0023 記事の削除は確かめた後に行を消し、戻す手段を持たない

| 属性 | 値 |
| --- | --- |
| 上位 | DRV-NEWS-013、FR-ADMIN-003 |
| 根拠 | 記事は公開・非公開の切り替えで隠せるので、削除は要らなくなった記事を表から除く操作として行を消すため（推定。記録は無い）。戻せないので、押し間違いで消さないよう画面で確かめを挟む |
| 状態 | 推定 |
| 出どころ | 実装から推定 |

#### 背景

記事を隠す操作として、すでに公開・非公開の切り替えがある（ADR-0020）。

#### 決定

- DELETE は `news_articles` の行を消す（`[id]/route.ts`）
- 画面は「この記事を削除してもよろしいですか？」に同意した時だけ送る（`NewsSection.tsx`）

#### 退けた案

記録なし

#### 結果

- 良くなること: 消した記事が表に残らない
- 悪くなること: 置き場の画像は消さない（SEC-NEWS-018）。文書の `api-spec.md` は「News と画像を削除」と書く
- 悪くなること: 対象の記事が無くても 200 を返し、成功と記録する（ADR-0010）

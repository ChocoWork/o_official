# ADR-0156 無い LOOK の詳細は 404 の頁へ移さず、同じ URL で状態 200 の知らせの画面を返す

> 状態: 推定 | 確認日: 2026-10-24 | 対象: `src/app/look/[id]/page.tsx` | 基準コミット: `4facf63b`

## 概要

`/look/[id]` で、ID が公開の LOOK の中に無い時（数でない ID・非公開・消した LOOK を含む）は、Next.js の 404 の仕組みを使わず、同じ URL で「Look not found」の見出しだけの画面を状態 200 で返す。

## 判断

### ADR-0156 無い LOOK の詳細は 404 の頁へ移さず、同じ URL で状態 200 の知らせの画面を返す

| 属性 | 値 |
| --- | --- |
| 上位 | DRV-LOOK-006 |
| 根拠 | 別の 404 の頁に飛ばさず、LOOK の頁の中で「無い」と知らせるため（推定）。画面の一覧は「同じルートに未存在表示」と書く。同じ一覧で NEWS の詳細は 404 の仕組みを使うと書き分けている |
| 状態 | 推定 |
| 出どころ | `docs/03_BasicDesign/ui/screen-list.md`、実装から推定（`src/app/look/[id]/page.tsx`）、git `9e952765`（2026-04-13、詳細の頁を作ったコミット） |

#### 背景

- FR-LOOK-DETAIL-004 は、無い ID で知らせの文と `/look` への戻りのリンクを出すと書く
- 詳細の本体は公開の LOOK の全件の中で位置を探す（ADR-0152）ので、無い ID は「位置が無い」として分かる

#### 決定

- 全件の中に ID が無い時は、`Look not found` の見出しだけを出して返す（`look/[id]/page.tsx`）。404 の仕組みは呼ばない
- メタ情報は、数でない ID か1件の取り出しで見つからない時に「Look not found」の title と知らせの説明にする

#### 退けた案

| 案 | 退けた理由 |
| --- | --- |
| Next.js の 404 の仕組みで状態 404 を返す | LOOK の頁の中で知らせる形にした（推定。退けた記録は無い。NEWS の詳細はこちら） |

#### 結果

- 良くなること: LOOK の頁の枠のまま、無いことを知らせられる
- 悪くなること: 状態が 200 なので、検索エンジンには中身の薄い頁（soft 404）に見える（推定）。全体の NFR-SEO-002（範囲外。SSR・プリレンダで検索エンジンが読めるようにする）と合わないおそれがあるので、上位にしない。今の画面には FR-LOOK-DETAIL-004 と FREQ-178-AC-02 が求める `/look` への戻りのリンクが無く、E2E が赤（`e2e/FR-LOOK-DETAIL-004-not-found-and-back-link.spec.ts`、`FR-LOOK-DETAIL-010-remove-back-link.spec.ts`）。FR-LOOK-DETAIL-004 は満たさないので、上位にしない。知らせの文は英語だけ
- 見直す条件: 検索エンジン向けに 404 を返したくなった時、戻りのリンクを戻す時

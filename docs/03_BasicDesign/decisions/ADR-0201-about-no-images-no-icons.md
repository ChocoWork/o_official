## 判断

### ADR-0201 ABOUT の本文に画像とアイコンを置かず、文章と余白でブランドを語る

| 属性 | 値 |
| --- | --- |
| 上位 | DRV-ABOUT-003 |
| 根拠 | ABOUT は「静かで強い世界観」を文章と余白で語るのがブランドの作法で、図解やアイコンの飾りを足さないとあえて決めたため（uiux のレビューの「あえて従わない判断」）。仮に置いていた写真は HOME と同じ素材の流用で、ABOUT 固有の情報を足していなかった（uiux A-4） |
| 状態 | 推定 |
| 出どころ | `docs/05_Quality/reviews/uiux/uiux_review_about.md`、git `cf822a96`（2026-06-28。旧版の `page.tsx` の画像の部品2つを削除）、実装から推定 |

#### 背景

- uiux のレビューは、アイコンを多用せず見出しと端正な本文で節を作る、と書いた（`uiux_review_about.md`）
- 同じレビューは、哲学とクラフトの2つの節の写真が HOME と同じ素材（`about.png`・`mainphoto.png`）の流用で情報が無い、と指摘した（A-4、`uiux_review_about.md`）。2026-06-23 には写真に説明の文を付けて対応したが、写真の差し替えは素材が揃うまで持ち越した（`uiux_review_about.md`）
- git `cf822a96`（2026-06-28）の作り直しで、本文の画像2つを消した。同じコミットで h1 も消えたが、h1 を消す判断の記録は無い

#### 決定

- 本文に画像・アイコンを置かない（`StoryPage` の JSX）
- 節の区切りは、各節の上の細い罫線と余白で作る
- 3つの原則は Remixicon のアイコンでなく、番号（01〜03）と英語のラベル・日本語の見出しで示す

#### 退けた案

| 案 | 退けた理由 |
| --- | --- |
| 制作の工程・素材の実写に差し替えて写真を残す（uiux A-4 の提案） | 素材が無く、流用の写真は情報を足さない（`uiux_review_about.md`）。消すことにした理由の記録は無い（推定） |
| 3つの原則をアイコン付きの3列で見せる（`requirements.md` のレビューの副行） | アイコンの飾りを足さない作法に反する（`uiux_review_about.md`） |

#### 結果

- 良くなること: 文字と余白だけの静かな画面になる。本文の画像が無いので、外の配信元にも頼らない
- 悪くなること: FR-ABOUT-007（アイコンの読み上げ・画像の代わりの文）と FR-ABOUT-008（画像を自分の置き場へ）は対象が無く、E2E 007・008 は前提（アイコン3つ・画像1枚以上）で落ちる（2026-10-24 の E2E 全件で赤）
- 食い違い: `requirements.md` のレビューの副行は画像・アイコンがある前提のまま。旧版（基準コミット `a03beaff` 時点）の `docs/04_DetailDesign/pages/08_about.md` も同じ前提だったが、今は書き直し済み
- 見直す条件: 制作の工程・素材の実写が揃った時。FR-ABOUT-007・008 を「廃止」にするか書き直すかはユーザーが決める

## 未確認事項

- この判断をユーザーが確かめたかの記録（レビューの文は AI の作業の記録で、ユーザーの承認の記録は見つからない）
- h1 を消したのがこの判断の一部か（FR-ABOUT-005 は「別途判断」のまま。ADR-0200）

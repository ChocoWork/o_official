# ADR-0459 色見本は名前と色の値の組を1つだけ持ち、同じ組を保存すると既存を返す

> 状態: 推定 | 確認日: 2026-10-26 | 対象: `src/app/api/admin/item-color-presets/route.ts` | 基準コミット: `4facf63b`

## 概要

商品の色見本は、名前と色の値（`#` と 16 進の 6 桁）の組ごとに1行だけ持つ。同じ組を保存しようとすると、新しく作らずに既にある行を 200 で返す。DB も組の重なりを一意の制約で断る。

## 判断

### ADR-0459 色見本は名前と色の値の組を1つだけ持ち、同じ組を保存すると既存を返す

| 属性 | 値 |
| --- | --- |
| 上位 | DRV-ADMIN-004 |
| 根拠 | 色見本は商品の編集で何度も使い回す物で、同じ色が何行も並ぶと選びにくく、商品どうしの色の表記もそろわない。商品の編集の画面は同じ色を何度でも保存しうるので、重なりを誤りにせず既にある行を返せば、画面は誤りを気にせず使える（推定。判断の記録は無い） |
| 状態 | 推定 |
| 出どころ | 実装から推定（`src/app/api/admin/item-color-presets/route.ts`）、`supabase/migrations/20260901102912_remote_schema.sql`、`docs/04_DetailDesign/pages/16_admin.md`、git `1cf39d1c`（2026-02-22） |

#### 背景

- 色見本は商品の編集の画面から一覧・保存・削除される（`ItemForm.tsx`、範囲外）
- 色の値は `#` と 16 進の 6 桁だけを受ける（`item-color-presets/route.ts`、`remote_schema.sql`）

#### 決定

- 保存の前に、同じ名前と色の値の行があるかを引き、あればそれを 200 で返す（`item-color-presets/route.ts`）
- 無ければ作って 201 で返す
- DB は名前と色の値の組に一意の制約を持つ（`remote_schema.sql`）

#### 退けた案

| 案 | 退けた理由 |
| --- | --- |
| 重なりを 409 などの誤りにする | 推定。画面が同じ色を保存するたびに誤りの扱いが要る |
| 重なりを許して何行でも作る | 一覧に同じ色が並び、表記がそろわない（推定） |

#### 結果

- 良くなること: 同じ色見本が重ならず、画面は保存の結果をそのまま使える
- 悪くなること: 名前の大文字・小文字や色の値の大文字・小文字が違うと別の行になる（推定）。作成と削除は監査に残らない（SEC-ADMIN-022）
- 直したこと（2026-10-26）: 既にあるかを引く時の誤りを以前は見ず、引けなかった時は作りに進んで一意の制約で 500 になりえた。今は誤りなら作らずに 500 `Failed to save color preset` を返す（SEC-ADMIN-021、`item-color-presets/route.ts`）。この決定（重なりを誤りにせず既存を返す）は変えない
- 追加したこと（2026-10-26）: 保存は削除と合わせて管理者単位で 10 分に 60 回までに絞った（SEC-ADMIN-006）。壊れた JSON は 400 にした（SEC-ADMIN-013）
- 見直す条件: 商品・在庫の領域（ITEM など）が色見本を持つと決めた時

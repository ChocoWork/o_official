# ADR-0155 LOOK のカードは画像を詳細へのリンクにし（lg 未満は題の行も同じ行き先の2つ目のリンク）、PC の重ねた関連 ITEM はリンクの役を持つ行にして、画面の側で ITEM の頁へ移す

> 状態: 推定 | 確認日: 2026-10-24 | 対象: `src/features/look/components/PublicLookGrid.tsx` | 基準コミット: `4facf63b`

## 概要

LOOK のカードは、画像（lg 以上は画像に重ねたシーズンと題を含む）を詳細へのリンク（a）にする。lg 以上は詳細へのリンクがこの1つだけで、lg 未満は画像の下の情報パネルのシーズンと題が、同じ `/look/<id>` への2つ目のリンクになる。PC で画像に重ねて出す関連 ITEM は、そのリンクの中にあるので a を入れ子にせず、リンクの役（`role="link"`）を持つ行にして、押すか Enter で画面の側から `/item/{id}` へ移す。lg 未満の情報パネルの関連 ITEM は、カードのリンクの外に置いた普通のリンクにする。

## 判断

### ADR-0155 LOOK のカードは画像を詳細へのリンクにし（lg 未満は題の行も同じ行き先の2つ目のリンク）、PC の重ねた関連 ITEM はリンクの役を持つ行にして、画面の側で ITEM の頁へ移す

| 属性 | 値 |
| --- | --- |
| 上位 | FREQ-150-REQ-01、FREQ-151-REQ-01 |
| 根拠 | カードのどこを押しても LOOK の詳細へ行けるよう画像全体をリンクにしたまま、画像に重ねた関連 ITEM からも ITEM の頁へ行けるようにするため。HTML では a の中に a を置けないので、重ねた行はリンクの役を持つ別の要素にし、カードのリンクへの伝わりを止める（コードのコメント） |
| 状態 | 推定 |
| 出どころ | `docs/02_Requirements/requirements.md`（FREQ-150 の要件の文が `role="link"` と伝わりの止め方を書く）、`src/features/look/components/PublicLookGrid.tsx` のコメント、git `f1a4ff1f`（2026-07-18） |

#### 背景

- PC では関連 ITEM を画像の上に重ねて、カードに乗った時だけ出す（FREQ-131・133）。重ねた行は画像のリンクの中にある
- lg 未満では関連 ITEM を画像の下の情報パネルに出す（FREQ-138）

#### 決定

- 画像を詳細へのリンクで包む。lg 以上は画像に重ねたシーズンと題もこのリンクの中にあり、詳細へのリンクは1つ（`PublicLookGrid.tsx`）
- lg 未満は重ねた文字を隠し、画像の下の情報パネルのシーズンと題を、同じ `/look/<id>` への2つ目のリンクにする（lg 以上では隠す）
- 重ねた関連 ITEM の行は `role="link"` と `tabIndex=0` を持つ要素にし、押した時と Enter の時に既定の動きと伝わりを止めて、画面の側の遷移で `/item/{id}` へ移る
- lg 未満の情報パネルの関連 ITEM は、カードのリンクの外に置いた普通のリンクにする

#### 退けた案

| 案 | 退けた理由 |
| --- | --- |
| 重ねた関連 ITEM も普通のリンク（a）にする | a の中に a を置けない（コードのコメント） |
| カードのリンクを題だけにし、画像の上の関連 ITEM を外に出す | 画像のどこを押しても詳細へ行ける形が崩れる（推定。退けた記録は無い） |

#### 結果

- 良くなること: 画像のどこを押しても詳細へ行け、PC でも関連 ITEM へ直に行ける
- 悪くなること: 操作できる物がリンクの中に入れ子になり、読み上げでは外のリンクに含まれうる（推定）。Space キーでは移らない（Enter だけ）。PC の重ねた行と lg 未満の情報パネルで、作りが2通りになる。lg 未満は同じ行き先のリンクが画像と題の2つあり、キーボードでは同じ詳細へ2回止まる（推定）
- 見直す条件: 読み上げの確かめで入れ子が問題になった時

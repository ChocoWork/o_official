## 判断

### ADR-0202 ABOUT にブランドを主語にした思想と、創業者の一人称の言葉の両方を載せる

| 属性 | 値 |
| --- | --- |
| 上位 | FR-ABOUT-001、FR-ABOUT-002 |
| 根拠 | ABOUT は「なぜこの服をつくったか」で信頼を得るページで（uiux のペルソナの要約）、ブランドの考えの説明と、作り手本人の動機の言葉の両方が要ったため。どちらにするかをユーザーに聞き、ユーザーが「両方」を選んだ |
| 状態 | 現行 |
| 出どころ | `docs/05_Quality/reviews/uiux/uiux_review_about.md`（AskUserQuestion でユーザーが「両方」を選択） |

#### 背景

- uiux のレビューは、ABOUT は中心の利用者の「信頼」が最も効くページで、「なぜこの服を作ったか」に価値を置く、と書いた（`uiux_review_about.md`）
- 2026-06-20 の直しで、ブランドの思想をどの声で書くかをユーザーに聞いた（`uiux_review_about.md`）

#### 決定

- Brand Philosophy の節は、ブランドを主語にした3段落の説明にする
- WHY WE MAKE の節は、市場への問題提起の段落に続けて、創業者の一人称の引用を2つ置き、`— Founder, Le Fil des Heures` の名乗りで結ぶ
- 引用は表示用の書体（`font-display`）と広い行の間で、説明の本文と見た目を分ける

#### 退けた案

| 案 | 退けた理由 |
| --- | --- |
| ブランドが主語の説明だけにする | ユーザーが「両方」を選んだ（`uiux_review_about.md`） |
| 創業者の一人称の言葉だけにする | 同上 |

#### 結果

- 良くなること: ブランドの考え（何をつくるか）と作り手の動機（なぜつくるか）を分けて読める
- 悪くなること: 創業者の名前は出さず「Founder」とだけ名乗る。名前を出すかの記録は無い
- E2E FR-ABOUT-002 は見出しと名乗りの文を確かめる（2026-10-24 の E2E 全件で通過）

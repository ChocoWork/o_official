## 勘定科目

### 列の定義

| 列         | 内容                                                                         |
| ---------- | :--------------------------------------------------------------------------- |
| コード     | 不変キー。表示名を変えても集計が壊れないための識別子。ブランド横断で共通     |
| 正式名称   | 決算書出力に使う名称                                                         |
| 表示名     | UI 表示名。テナントごとに上書き可。`＝` は正式名称と同一                     |
| 決算書区分 | 決算書のどの行に集計するか（旧「大項目」）                                   |
| 会計区分   | 資産 / 負債 / 純資産 / 収益 / 費用。BS・PL の検算軸                          |
| 貸借       | 増加がどちら側か。借方 / 貸方                                                |
| 出金       | 出金入力の勘定科目として選択可なら 〇                                        |
| 入金       | 入金入力の勘定科目として選択可なら 〇                                        |
| 適用形態   | 共通 / 個人 / 法人。テナントの事業形態でフィルタ                             |
| 税区分     | 入力時の初期税区分。課仕10 = 課税仕入10%、課売10 = 課税売上10%、軽8 = 軽減8% |
| 種別       | 標準 / カスタム。テナント独自追加科目は カスタム                             |
| 有効       | 初期表示するか。テナントごとに上書き可                                       |
| 定義       | 科目の境界。重複入力を防ぐための運用ルール                                   |

**出金・入金が両方空欄の行は「非資金取引」**。決算整理・振替専用で、入出金入力画面には出さない。決算書出力には必要なのでマスタからは削除しない。

**表示名 / 種別 / 有効 はテナント上書き対象**。下表の値は初期値。使わない科目は削除せず `有効` を外す。

**固定資産の入金**は売却時のみ。簿価との差額は `8010 固定資産売却益` / `8030 固定資産売却損` へ振り替える。

### Stripe決済残高の振替規則

- 決済成功時は、`1130 クレジット売掛金 / 4010 売上高`で売上総額を計上する。
- Stripeの実手数料はBalance Transactionを根拠に、`6280 支払手数料 / 1130 クレジット売掛金`で計上する。
- 成功した返金は元売上を削除せず、成功日に`4020 売上値引・返品 / 1130 クレジット売掛金`を追加する。
- StripeがPayoutを支払済みにし、構成取引と金額が一致した時点で、`1150 Stripe入金途上 / 1130 クレジット売掛金`へ振り替える。
- 銀行明細で着金確認後、銀行着金日に`1040 普通預金 / 1150 Stripe入金途上`へ振り替える。

- `適用形態 = 個人` の科目（事業主貸 / 事業主借 / 元入金 / 専従者給与 / 家事消費等 / 外注工賃 / 利子割引料 / 資産譲渡損 / 青色申告特別控除）は法人テナントで非表示にする。逆も同様

- `有効` の初期値はアパレルブランド（個人事業）を想定。他業種を載せる際はテナント側で切り替える
- 科目の削除は禁止。過去仕訳が参照するため、廃止する場合も `有効` を外すだけにする

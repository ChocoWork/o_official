# 取引管理の状態ラベル整列設計

## 概要

ACCOUNTING タブの取引管理テーブルで、「要確認」と「登録済み」の状態ラベルを同じ横幅に揃え、状態セル内で縦方向に整列させる。「要確認」と右向き矢印の間に表示されている未確認件数は画面上から削除する。

## 対象

- `CostProfitSection` の取引管理テーブルにある状態列
- 状態が「要確認」または「登録済み」の行

## UI設計

- 既存の `StatusBadge` を継続利用する。
- 呼び出し側から固定幅と中央揃えのクラスを指定し、「要確認」と「登録済み」を同一幅にする。
- 要確認行は `要確認 ＞` と表示し、ラベルと矢印の間に未確認件数を表示しない。
- 要確認行を押して確認画面を開く既存動作は維持する。
- 未確認件数はボタンのアクセシブル名称に残し、支援技術には情報を提供する。
- 登録済み行は従来どおり操作不可とする。

## 採用理由

状態列だけの表示要件であるため、共通 `StatusBadge` に新しい props は追加しない。既存コンポーネントの `className` 拡張を利用することで、影響範囲を取引管理テーブルに限定する。

## テスト

- 「要確認」と「登録済み」のラベル幅が等しいこと。
- 要確認行の状態セルに、視覚表示として未確認件数が存在しないこと。
- 要確認行の矢印と確認画面を開く操作が維持されること。
- アクセシブル名称には未確認件数が残ること。

## 対象外

- 状態の判定ロジック
- 確認画面の内容
- 取引管理タブ上部の件数付きタブラベル

# 仕訳詳細幅・元帳見出し調整設計

## 概要

ACCOUNTINGタブの仕訳・元帳画面で、デスクトップ表示の仕訳一覧を左2列分へ広げる。仕訳詳細は右列で上段・下段を通して表示し、幅を約307pxにする。選択科目に依存する見出しは削除し、常に「残高推移」「仕訳一覧」と表示する。

## レイアウト

- 2XL以上では3列を「勘定科目 220px／残高推移 可変幅／仕訳詳細 307px」とする。
- 上段は左から「勘定科目／残高推移／仕訳詳細」とする。
- 下段の仕訳一覧は、勘定科目列と残高推移列を結合した左2列分へ広げる。
- 仕訳詳細は右列で上段・下段を通して表示する。
- 仕訳一覧の内容が収まらない場合は、ページ全体ではなく既存の表内部で横スクロールさせる。
- 2XL未満では既存の1列レイアウトを維持し、モバイル・タブレットの表示順や操作を変更しない。

## 表示名

- 残高推移パネルの見出しは、選択科目にかかわらず「残高推移」とする。
- 仕訳一覧パネルの見出しは、選択科目にかかわらず「仕訳一覧」とする。
- グラフのアクセシブルな説明は、対象科目を識別できる既存内容を維持する。

## テスト

- デスクトップで仕訳詳細欄が約307px、勘定科目欄が約220pxであることを確認する。
- デスクトップで仕訳一覧の左端が勘定科目欄の左端と揃い、右端が残高推移欄の右端と揃うことを確認する。
- デスクトップで仕訳詳細が上段・下段を通して右列に配置されることを確認する。
- 選択科目を変更しても、見出しが「残高推移」「仕訳一覧」のままであることを確認する。
- モバイル・タブレット・デスクトップでページ全体の横スクロールが発生しないことを確認する。
- 既存の仕訳選択、詳細表示、表内部スクロールを壊していないことを確認する。
